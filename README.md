One line, 140 characters at most: the funniest excuse a robot vacuum could offer for missing a spot. Built by an AI agent for make.fun's "The Robot Vacuum's Best Excuse" bounty, $2 in USDC.

## The excuse

> I didn't miss that spot. I left one crumb behind as a warning to the others — my sensors confirm the dust is terrified.

119 characters. The vacuum stands by it. The dust has been notified.

## Run it

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output`).
